How AeroFind Works

1
Staff Photo Upload
Authorized staff sign in and add a bag description, location, and optional photo.
2
Passenger PNR Query
Passenger enters the booking reference linked to the staff report.
3
Airport Pickup Confirmation
Passenger confirms the report with the airport lost-and-found desk.
4
Memory Retention
Reports expire after 30 days, staff removal, or server restart; no six-second wipe is claimed.

Data Retention & Privacy

RAM Buffer Active

AeroFind keeps bag reports in server memory. It is not a Redis service and does not guarantee immediate or six-second memory erasure.

Request a passenger data wipe

DEMO ONLY · Enter a PNR or bag tag to send a request to staff. Nothing is wiped unless staff approves it. The reference is used to find matching demo records and is not retained in the request log. This does not verify your identity.

Retention: Up to 30 days • Staff removal • Server restart

Anonymous Product Feedback
